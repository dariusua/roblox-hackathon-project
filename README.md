# roblox-hackathon-project
# BlatIndex UA - Аналіз «блатності» автономерів України

Автомобільний номер в Україні давно вийшов за межі звичайного ідентифікатора транспорту - це окремий культурний феномен, індикатор статусу та предмет колекціонування на дорогах. Проєкт досліджує феномен «блатних» і красивих номерних знаків по всіх регіонах України на основі відкритих державних даних.

## Що збирає та рахує аналіз

Під час обробки реєстру транспортних засобів МВС (`N_REG_NEW`) система формує два рівні статистики - загальну по базі та детальну по кожному регіону.

**Загальна статистика обробки:**
- `records_read` - загальна кількість прочитаних записів із файлу реєстру.
- `unique_plates` - кількість унікальних стандартних номерних знаків, що потрапили у фінальний зріз.
- `duplicate_records` - кількість повторних записів (перереєстрацій одного й того самого номера), які відсіюються для чистоти статистики.
- `nonstandard_records` - кількість індивідуальних, транзитних або нестандартних номерів, винесених за межі основного рейтингу.

**Аналітика по кожній області (`regions`):**
- `unique_plates` - загальна кількість унікальних автомобілів, закріплених за регіоном (нові та спеціальні коди виокремлюються у категорію «Невідомий регіон»).
- `capitalization_uah` - сумарна оціночна вартість усіх номерних знаків області в гривнях за офіційною сіткою тарифів МВС.
- `average_score` - середній «індекс блатності» номера в регіоні.
- `average_price_uah` - середня оціночна вартість одного номера в області.
- `most_expensive_plate` - найдорожчий та найрідкісніший номерний знак регіону (за однакової ціни обирається перший за алфавітом).

## Навіщо це потрібно

Проєкт перетворює сирий державний масив даних про реєстрацію автомобілів на зрозумілу аналітику, яка показує реальну «капіталізацію» номерних знаків на дорогах, регіональні вподобання автовласників та географію розподілу ексклюзивних комбінацій по Україні.
